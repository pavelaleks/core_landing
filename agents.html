Data discovery agent

Task
Find data for a research question and check it against the requirements.
Connection
Submit a task through the website or API. Delegation from an external agent could be added through A2A.
Output
A justified selection with file availability, access terms and data gaps.
Readiness
Agent — concept

A catalog and scripts for checking files in research repositories are available.

Data preparation agent

Task
Inspect files, map fields and transform the data into a specified schema.
Connection
Provide files, a target schema and rules through the website or API. Receive a task ID.
Output
Prepared files, a field dictionary and a report on transformations, quality and unresolved questions.
Readiness
Agent — concept

Preparation scripts and demonstration packages for three datasets are available.

Data analysis agent

Calculations, reproducible code, sources and limitations of the findings.

Who studies a similar problem

Task
Find universities and research groups working on a similar problem.
Connection
API or MCP. The agent provides a problem description, methods and search constraints.
Output
Candidates, publications with dates and source links, an explanation of the match and related datasets.
Readiness
Service — concept

Links between universities, publications and research areas are available. Finding individual researchers requires author IDs and affiliations.

API. The agent provides documents or links and receives an index ID.

Data computation

Task
Run SQL filtering, joins and aggregation close to large datasets.
Connection
API. The agent sends a query against selected dataset versions and receives a task ID.
Output
Execution status, a result table or file link, and calculation parameters.
Readiness
Service — concept

A local in-browser SQL demonstration exists. A server-side computation API is proposed.

Example workflow

A proposed workflow for preparing data for analysis or model training.

  1. Your agent

    Finds source data

    Uses MCP to identify a university, find datasets and inspect their schemas. Selects materials for the task.

  2. CORE agent

    Prepares the data

    Receives the task and target schema, chooses transformations and checks the result.

  3. Your agent

    Uses the result

    Retrieves files and a report using the task ID. Continues the analysis or passes the dataset to a training process.

Connection methods

Choose an interface based on the operation and the customer's application.

MCP

Call tools from an agent application. The CORE connection is at the concept stage.

HTTP API

Direct requests and client libraries. A static JSON API and an OpenAPI description are currently available.

A2A

Delegate tasks to CORE agents and exchange status updates. A proposed interface.

Webhooks

Receive events about new data versions. A proposed interface.
