Для: всех, кому нужно то, чего нет в открытом доступе

Почему не скачать бесплатно с Zenodo или Hugging Face?

Открытое ≠ готовое

Из 548 записей учёных ЦА, которые выглядят как датасеты, мы открыли каждую: у 143 (26%) данных нет — только статья в PDF, закрытые файлы или удалённая запись.

Сырые форматы

В найденных наборах — итоговые баллы формулами Excel, коды чувствительности в шести вариантах, названия микробов свободным текстом по-русски. Мы приводим к стандартам (МКБ-10, LOINC, ATC) и описываем каждое поле на трёх языках.

Права по каждой записи

Лицензия, основание, авторы и проверка персональных данных — в паспорте набора и в каждой записи, а не «где-то на странице репозитория».

То, чего нет в сети

Главное — архивы вузов, которые никогда не публиковались. Их мы открываем по договору с вузом. Хорошие открытые наборы (например, корпус казахской речи ISSAI) мы не перепродаём — подскажем, где взять их бесплатно.

Как это работает для покупателя

  1. НайдитеКаталог, паспорт данных, схема полей и метрики качества — открыто.
  2. Проверьте образецБесплатный образец любого набора из каталога (до 1 000 записей) за 24 часа после заявки.
  3. ЛицензируйтеСтандартная неисключительная лицензия на срок или индивидуальный договор с DPA.
  4. ПолучитеAPI, выгрузка Parquet/JSONL, приватный репозиторий Hugging Face или S3. Обновления по подписке.

Договор и требования к данным

Лицензия

Неисключительная, на срок, для обучения, дообучения и оценки моделей. Нельзя перепродавать данные как есть и пытаться установить личность. Указание источника — по условиям набора.

Персональные данные

Обезличиваем до передачи. Для данных о людях — соглашение об обработке (DPA). Хранение — по закону Узбекистана о персональных данных.

Происхождение

У каждой записи — источник, лицензия, правовое основание и дата; в паспорте — отчёт о качестве и журнал изменений.

Документы

Образец лицензии, DPA и реквизиты — по запросу. Тексты проходят проверку юриста; до подписания согласуем их под вашу задачу.

Для ИИ-агентов · превью

Подключите граф CORE к своему агенту

MCP-сервер CORE отдаёт агенту только те данные, на которые у вас есть лицензия, — и в каждом ответе указывает ID записи, источник и лицензию. Агент цитирует, а не выдумывает.

  • Только лицензированные данные: агент не видит лишнего
  • Каждый факт — с ID записи и ссылкой на источник
  • Поиск по графу: вузы, направления, датасеты, регионы
  • Будет работать с любым клиентом, который поддерживает MCP: Claude, ChatGPT, Cursor
