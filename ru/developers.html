Как это работает для покупателя

  1. НайдитеКаталог, паспорт данных, схема полей и метрики качества — открыто.
  2. Проверьте образецБесплатный образец до 1 000 записей за 24 часа после заявки.
  3. ЛицензируйтеСтандартная неисключительная лицензия на срок или индивидуальный договор с DPA.
  4. ПолучитеAPI, выгрузка Parquet/JSONL, приватный репозиторий Hugging Face или S3. Обновления по подписке.

Для ИИ-агентов · превью

Подключите граф CORE к своему агенту

MCP-сервер CORE отдаёт агенту только те данные, на которые у вас есть лицензия, — и в каждом ответе указывает ID записи, источник и лицензию. Агент цитирует, а не выдумывает.

  • Только лицензированные данные: агент не видит лишнего
  • Каждый факт — с ID записи и ссылкой на источник
  • Поиск по графу: вузы, направления, датасеты, регионы
  • Будет работать с любым клиентом, который поддерживает MCP: Claude, ChatGPT, Cursor
mcp.json · макет, адрес появится при запуске
{ "mcpServers": { "core": {
    "url": "https://mcp.core-data.example/v1",
    "headers": { "Authorization": "Bearer $CORE_KEY" }
} } }

Как выглядит размеченная запись: пять шагов

От исходного текста до файла, который можно сразу подать модели: отметки в тексте, ссылки на справочники, проверка экспертом и права на каждую запись. Нажимайте на шаги слева.

Supporting data for “New records and habitat modeling of Limnatis paluda (Praobdellidae) in southern Uzbekistan”

This dataset contains supporting data for a study of Limnatis paluda in Uzbekistan, including occurrence records, specimen and habitat photographs, COI sequence and alignment data, haplotype-network files, and MaxEnt habitat-suitability modeling outputs. The study documents new records from southern Uzbekistan and evaluates current and projected habitat suitability under the SSP3-7.0 climate scenario.

Права и проверка

  • Лицензия CC-BY: коммерческое использование с атрибуцией
  • Основание: открытая лицензия, Zenodo
  • Персональных данных нет; имена авторов в каталог не выводятся
  • «Южный Узбекистан» → какой регион? Такие вопросы решает эксперт вуза — после подписания договора

Текст + разметка спанами + связи с ID + лицензия на каждую запись. Можно сразу учить NER, строить RAG с цитированием или собирать бенчмарк.
