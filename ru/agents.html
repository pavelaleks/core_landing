Справочник вузов

Задача
Определить вуз по названию с учётом языка и вариантов написания.
Подключение
MCP. Агент передаёт название, страну, город или внешний ID.
Результат
Кандидаты, постоянные ID CORE, сведения об организациях и источники.
Готовность
MCP — концепция

Есть справочник с постоянными ID и публичный JSON API.

Пример взаимодействия

Предлагаемый сценарий подготовки данных для анализа или обучения модели.

  1. Ваш агент

    Находит исходные данные

    Через MCP определяет вуз, находит наборы и изучает их схемы. Выбирает материалы для задачи.

  2. Агент CORE

    Выполняет подготовку

    Получает поручение и целевую схему, выбирает преобразования и проверяет результат.

  3. Ваш агент

    Использует результат

    Получает файлы и отчёт по ID задачи. Продолжает анализ или передаёт набор в процесс обучения.

Способы подключения

Интерфейс выбирается под операцию и возможности программы заказчика.

MCP

Вызов инструментов из программы агента. Подключение CORE описано как концепция.

HTTP API

Прямые запросы и клиентские библиотеки. Сейчас есть статический JSON API и описание OpenAPI.

A2A

Передача поручений агентам CORE и обмен статусами. Предлагаемый интерфейс.

Вебхуки

Доставка событий о новых версиях данных. Предлагаемый интерфейс.
