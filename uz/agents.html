Oʻzaro ishlash misoli

Tahlil yoki modelni oʻqitish uchun maʼlumot tayyorlashning taklif etilayotgan ssenariysi.

  1. Sizning agentingiz

    Boshlangʻich maʼlumotlarni topadi

    MCP orqali universitetni aniqlaydi, toʻplamlarni topadi va sxemalarini oʻrganadi. Vazifa uchun materiallarni tanlaydi.

  2. CORE agenti

    Tayyorlashni bajaradi

    Vazifa va maqsadli sxemani oladi, oʻzgartirishlarni tanlaydi va natijani tekshiradi.

  3. Sizning agentingiz

    Natijadan foydalanadi

    Vazifa ID si orqali fayllar va hisobotni oladi. Tahlilni davom ettiradi yoki toʻplamni oʻqitish jarayoniga uzatadi.

Ulanish usullari

Interfeys amal va buyurtmachi dasturining imkoniyatlariga qarab tanlanadi.

MCP

CORE ochiq serveri: universitetlar, olimlar, nashrlar va maʼlumotlar toʻplamlari. Streamable HTTP transporti, kalit kerak emas.

https://jjwzntypllcumagzbdcn.supabase.co/functions/v1/core-mcp

Claude Code:

claude mcp add --transport http core https://jjwzntypllcumagzbdcn.supabase.co/functions/v1/core-mcp

Claude Desktop va claude.ai: Settings → Connectors → Add custom connector, oʻsha URL. Boshqa mijozlar bu URL’ni MCP server sifatida ulaydi.
